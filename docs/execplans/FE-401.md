# FE-401 ExecPlan

## Goal

把 `/advanced` 里的 intelligence 区块升级为真正可操作的 control panel：管理员可 preview / dispatch / refresh，普通用户只看状态说明，且不破坏现有 AI 搜索、AI Prompt 和总览卡片。

## Scope

- 收敛 `resources/views/user/advanced_overview.blade.php` 的 intelligence UI
- 补 `tests/Feature/Advanced/AdvancedFeaturePagesTest.php` 页面级回归
- 记录 FE-401 实施边界与验证命令

## Constraints

- 不回退并行任务已经落地的 control plane backend
- 不改 `UserController` 业务逻辑，除非出现前端无法适配的阻塞
- 保持普通用户 `/advanced` 可访问，但不暴露 admin-only 操作位
- 不影响现有 overview 指标卡、功能入口卡、AI 搜索和 AI Prompt 页面入口

## Implementation Notes

- 页面操作端点改为消费 backend `control_plane` payload，不在 Blade 里硬编码 intelligence API 路径
- admin control panel 的按钮禁用态、默认参数和 scheduler 提示都从 payload 派生
- 页面测试同时覆盖 admin 可见 control panel 与普通用户不可见操作位

## Validation

- `./vendor/bin/phpunit --filter=AdvancedFeaturePagesTest`
- `./vendor/bin/phpunit tests/Feature/Intelligence/IntelligenceControlPlaneTest.php`

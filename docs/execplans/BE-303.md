# BE-303 ExecPlan

## Goal

深化 Prompt V2 的上下文构建，让 intelligence 缺失、processing、failed、ready 时都有明确状态与 hint，并补充横图、竖图、方图方向信息。

## Scope

- 收敛在 `ImagePromptContextBuilder`
- 必要时适配 `GenerateAiPromptTaskJob`
- 补 focused intelligence tests

## Constraints

- 不把状态/方向逻辑回堆到 `AiPromptService`
- 不回退并行 worker 已有改动
- 仅在需要时扩大写集

## Implementation Notes

- 缺失 intelligence record 时显式输出 `analysis_status=missing`
- 对 `pending` / `processing` / `failed` / `ready` 生成不同 `analysis_hint`
- 增加 `orientation`、`orientation_label`、`orientation_hint`
- 保持 ready 时优先用 intelligence 字段，非 ready 时根据已有片段决定 `context_source`

## Validation

- `php -l app/Services/ImageIntelligence/ImagePromptContextBuilder.php`
- `php -l tests/Feature/Intelligence/AiPromptContextBuilderTest.php`
- `./vendor/bin/phpunit --filter=AiPromptContextBuilderTest`

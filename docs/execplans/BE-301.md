# BE-301 ExecPlan

## Goal

补齐 image intelligence 的旧图回填与调度入口，提供独立 command/service，不把复杂逻辑重新塞回 `ImageService`。

## Status

- 已新增 artisan command
- 已接入最小安全 scheduler
- 已补 focused tests 并完成验证

## Scope

- 新增 `App\Services\ImageIntelligence\ImageIntelligenceBackfillService`
- 新增 `images:backfill-intelligence` command
- 薄改 `app/Console/Kernel.php`
- 新增 focused command tests
- 更新执行文档

## Constraints

- 不把回填逻辑塞回 `ImageService`
- 兼容现有上传写侧派发路径
- 仅做最小安全调度，不扫全库、不阻断上传主流程
- 适配并行工作区，不回退其他 worker 修改

## Implementation Notes

- `ImageIntelligenceBackfillService` 负责筛选候选图片，并统一执行 dry-run / dispatch
- 候选范围默认包括：
  - 缺失 `image_intelligence_records` 的旧图片
  - intelligence record 不完整或非 `ready`，且超过冷却窗口的图片
- `images:backfill-intelligence` 默认 dry-run，需显式传 `--dispatch` 才会派发任务
- intelligence record 现在具备最小状态流：`pending -> processing -> ready`，异常时写回 `failed`
- scheduler 每小时只处理 25 张、只看 30 分钟前的图片，作为最小安全自动回填入口

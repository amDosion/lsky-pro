# ExecPlan PO-201

## Goal

固化第二轮范围、验收边界和不做项，把队列切换到 AI intelligence foundation + settings shell + auth matrix shell + social auth hardening。

## Decisions

- 图像智能分析本轮先做结构化写侧骨架，不追求完整 OCR/CV 质量。
- AI 检索与 Prompt V2 分离为读侧消费层，避免继续堆在控制器和 `AiPromptService`。
- 系统设置页和登录矩阵优先做壳层，不改核心保存接口和 OAuth 路由。
- 认证把社交登录 hardening 纳入本轮，不把 Passkey 讨论停留在纯 UI。

# FE-402 ExecPlan

## Goal

把设置页里的 Passkey 与身份状态从静态占位升级为真实 backend status 展示，基于 BE-403 的 `auth_identities` 与 Passkey foundation 接口输出页面状态，但不伪装完整 Passkey 产品已经完成。

## Scope

- 改造 `resources/views/user/settings.blade.php`
- 扩展 `tests/Feature/User/SettingsPageTest.php`
- 保持现有设置页结构和密码 / Google / GitHub / Passkey 共存语义

## Constraints

- 不改 controller
- 不破坏现有设置页布局层次
- 不假装 WebAuthn 注册校验、登录验证、设备管理已经上线
- 保持与 legacy `users.provider*` snapshot 的兼容说明

## Implementation Notes

- 设置页加载后调用 `route('passkeys.status')`
- Google / GitHub 卡片以后端 `auth_identities` 结果为准更新“当前已关联 / 站点已接入 / 站点未接入”
- Passkey 卡片展示 foundation readiness、verification 开关、credential count、pending registration challenge
- 页面显式提示：foundation 已接入不等于完整 Passkey 产品已完成

## Validation

- `./vendor/bin/phpunit tests/Feature/User/SettingsPageTest.php`
- 如需交叉确认接口契约，可复跑 `./vendor/bin/phpunit --filter=PasskeyFoundationTest`

# BE-402 ExecPlan

## Goal

把 cycle-3 的 tag visibility bridge 升级为 first-class intelligence term projection：搜索和展示统一读取 `image_intelligence_terms`，不再从 `image_intelligence_records.labels/keywords` 临时回退，同时保持真实 manual `tags / image_tag` 不被污染。

## Scope

- 收敛 `ImageIntelligenceTermProjectionService` 的 projection contract
- 改造 `ImageTagVisibilityBridgeService` 仅消费 projection
- 调整 `AiSearchService` 仅把 projection 作为 intelligence term 搜索入口
- 让用户工作台 AI 搜索列表与详情页统一返回 `manual_tags / intelligence_tags / visible_tags`
- 补 focused intelligence feature tests

## Constraints

- 不改正在并行进行的 BE-401 control plane 路由/控制器
- 不把 intelligence terms 写入真实 `tags` 或 `image_tag`
- 不回退别人的本地改动；如发现并行变更，按当前 workspace 适配

## Implementation Notes

- projection 成为唯一的 intelligence term authority，`labels/keywords` 仅作为写侧原始输入保留
- 非 ready/completed 状态不应顺手清空既有 projection，避免 re-analysis 窗口导致读侧标签闪断
- bridge 应避免重复 decorate 时把已覆盖的 `tags` 误当成 manual tags

# BE-203 ExecPlan

## Goal

收敛密码登录与社交登录的关键 web session 约束，至少覆盖冻结账号校验和 remember/session 策略。

## Scope

- 新增统一 web session auth 服务
- 薄改 `LoginRequest`
- 薄改 `SocialAuthController`
- 补 auth feature tests

## Constraints

- 不改 login/register Blade
- 不做完整 Passkey backend
- 保持现有 Google/GitHub 路由可用

## Findings

- 当前分支已经引入 `App\Services\Auth\WebSessionAuthService`，并被密码登录与社交登录共同使用。
- `LoginRequest` 已在密码校验成功后复用统一冻结账号校验，冻结时强制登出并返回错误。
- `SocialAuthController` 已改为通过统一 session service 登录，默认 `remember=false`，冻结账号会被拦截。

## Implementation

- 保持现有生产代码路径不扩写，避免和并行 worker 冲突。
- 补充 auth feature tests，覆盖密码登录 remember cookie 策略。
- 补充 GitHub OAuth redirect 可用性测试，确保现有 provider 路由未被 hardening 回归影响。

## Validation

- PHP lint for changed PHP files
- `AuthenticationTest`

## Status

- Production hardening paths verified against current branch state
- Regression coverage expanded

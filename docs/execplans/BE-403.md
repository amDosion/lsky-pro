# BE-403 ExecPlan

## Goal

建立多身份模型与 Passkey/WebAuthn backend foundation 的最小安全起步方案，在不伪装完整产品已完成的前提下，为后续 FE-402 提供真实 backend 状态与基础接口。

## Scope

- 新增 `auth_identities`
- 新增 `webauthn_credentials`
- 新增身份同步服务与 Passkey challenge/status 服务
- 改造 `SocialAuthController`
- 补认证和 Passkey foundation tests

## Constraints

- 不改设置页 Blade
- 不碰主代理正在进行的 BE-401 control plane
- 保持现有 Google/GitHub 登录兼容
- 不伪装完整 WebAuthn 验证已经上线

## Implementation Notes

- 社交登录改为优先读 `auth_identities`，并继续同步 legacy `users.provider/provider_id/provider_avatar`
- `auth_identities` migration 会回填现有 legacy provider 数据
- Passkey foundation 只提供 authenticated status 和 registration options challenge，不实现 attestation verification

## Validation

- `php -l app/Services/Auth/PasskeyChallengeService.php`
- `php -l app/Http/Controllers/Auth/SocialAuthController.php`
- `php -l tests/Feature/Auth/AuthenticationTest.php`
- `php -l tests/Feature/Auth/PasskeyFoundationTest.php`

- `./vendor/bin/phpunit --filter=PasskeyFoundationTest`

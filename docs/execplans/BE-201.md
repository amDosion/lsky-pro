# BE-201 ExecPlan

## Goal

建立 image intelligence 写侧最小骨架：新表、新模型、新 job、新 service，并把上传后派发入口从 legacy OCR placeholder 挂到新的结构化记录层。

## Status

- 已完成最小写侧骨架落地
- 已接入上传后异步派发
- 已兼容同步 legacy `images.ocr_text`
- 已补定向测试并完成容器内验证

## Scope

- 新增 `image_intelligence_records` migration
- 新增 `ImageIntelligenceRecord` model
- 新增 `AnalyzeImageIntelligenceJob`
- 新增 `App\Services\ImageIntelligence\ImageIntelligenceService`
- 薄改 `ImageService` 和 `Image` 以接入 relation / dispatch

## Constraints

- 不改 AI 检索控制器
- 不改 `AiPromptService`
- 不改 auth 页面和 admin settings
- 第一版允许 metadata-derived placeholder，但必须写入结构化记录层
- 适配当前并行工作区，不回退其他 worker 修改

## Implementation Notes

- 新表采用单表 `image_intelligence_records`，按 `image_id` 唯一约束保存一条最新结构化记录
- `ImageIntelligenceService` 第一版使用图片元数据、尺寸、标签和文件名生成 placeholder caption / summary / prompt_hint / labels / keywords / metadata
- 上传主流程改为派发 `AnalyzeImageIntelligenceJob`，不再依赖旧 OCR placeholder job
- 为兼容旧接口，结构化记录写入后会静默同步 `images.ocr_text`

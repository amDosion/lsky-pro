# Lsky-Pro 仪表盘 (Dashboard 4.0) 深度优化方案

## 1. 核心问题诊断
* **主次不分**：管理员数据在管理员视角下喧宾夺主，干扰了对个人数据的关注。
* **布局松散**：顶部统计卡片信息密度过低，页面下方信息冗余。
* **缺乏引导**：快捷入口视觉吸引力不足，没有体现出“上传”作为第一操作的优先级。
* **交互静态**：配额和状态展示缺乏动态预警和智能化建议。

---

## 2. 优化原则
1. **行动导向**：强化上传和管理入口，缩短操作路径。
2. **层次分明**：区分个人数据、系统配额和（可选的）管理统计。
3. **视觉现代化**：引入更具科技感的图表组件和渐变色设计，提升仪表盘的“专业感”。

---

## 3. 模块化设计方案

### A. 核心数据 Hero 区
* **重构**：采用三列或四列布局，展示：图片总数、占用空间、今日上传、账户安全天数。
* **视觉**：背景采用极简灰白或深蓝色调，数字加粗放大。

### B. 资源管理中心 (左侧)
* **容量管理**：引入动态环形或胶囊进度条，增加“预计剩余天数”预测。
* **策略展示**：使用图标标识策略类型（本地/云端），高亮当前正在使用的默认策略。

### C. 快捷行动中心 (右侧)
* **按钮升级**：将“立即上传”设计为醒目的品牌色大按钮。
* **账户名片**：展示头像、组别和安全认证状态。

### D. 管理员视图优化
* **组件化**：将原本巨大的 ECharts 和统计网格收纳进一个“管理概览”专用区域，支持折叠/展开。

---

## 4. 技术方案
1. **布局适配**：使用 CSS Grid 重新定义 `body-grid`，实现更灵活的响应式切换。
2. **状态驱动渲染**：在 JS 中增加对容量阈值的逻辑判断，根据百分比动态切换 CSS 类名。
3. **ECharts 增强**：优化图表的交互性能，减少页面首屏加载负担。
